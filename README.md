# تست‌یار 📝

وب‌اپ فارسی و راست‌به‌چپ (RTL) برای **ساخت، برگزاری و تصحیح آزمون‌های تستی چهارگزینه‌ای** — سبک، سریع و قابل نصب روی موبایل (PWA).

## امکانات

- ساخت آزمون با نام، تعداد سوال، زمان (دقیقه) و دسته‌بندی (۱۴ دستهٔ پیش‌فرض + سایر) و اعتبارسنجی کامل ورودی‌ها
- صفحهٔ آماده‌سازی؛ تایمر فقط با زدن «شروع آزمون» آغاز می‌شود
- پاسخ‌برگ اسکرول‌شونده با سربرگ چسبان (نام آزمون | تایمر | شمارندهٔ پاسخ) + نوار پیشرفت + پرش به سوال
- تایمر **مبتنی بر ساعت واقعی** (`startedAt`/`endsAt` مطلق): با رندر مجدد، بستن برنامه یا رفتن به پس‌زمینه دقیق می‌ماند و قابل دور زدن نیست
- پایان زمان → قفل کامل پاسخ‌برگ + اورلی تمام‌صفحهٔ «زمان آزمون تمام شد» با دکمهٔ «ورود به تصحیح‌کننده»
- پایان دستی زودتر از موعد با تأییدیهٔ «ادامه آزمون / پایان آزمون»
- تصحیح‌کنندهٔ جدا: کلید صحیح جدا از پاسخ‌های کاربر وارد می‌شود؛ هشدار کلید ناقص با شمارهٔ سوال‌های بدون کلید
- وضعیت هر سوال: درست / غلط / نزده
- محاسبات دقیق: درصد بدون نمره منفی و درصد با نمره منفی `(درست − غلط÷۳) ÷ کل × ۱۰` — مقدار خام جدا از مقدار نمایشی، نمایش حداکثر با دو رقم اعشار
- صفحهٔ نتیجه با نمودار نسبت پاسخ‌ها و مرور سوال‌به‌سوال
- تاریخچهٔ کامل آزمون‌ها + ذخیرهٔ پایدار در `localStorage` (هیچ پاسخی گم نمی‌شود)
- PWA: قابل نصب، آفلاین با سرویس‌ورکر، فونت آفلاین وزیرمتن، آیکن و manifest فارسی RTL

## اجرا

```bash
npm start          # سرو در http://localhost:8080
```

یا هر سرور استاتیک دیگری روی ریشهٔ پروژه (بدون نیاز به build).

## تست‌ها

```bash
npm install        # فقط برای وابستگی توسعهٔ jsdom
npm test           # ۳۳ تست: محاسبات، تایمر، مدل، مخزن و سرتاسری UI
npm run check      # بررسی یکپارچگی importها، مراجع index.html و precache سرویس‌ورکر
```

سناریوهای پوشش‌داده‌شده در تست‌ها:

| # | سناریو | پوشش |
|---|--------|------|
| ۱ | ۲۰ سوال، ۱۴ درست، ۴ غلط، ۲ نزده → ۷۰٪ و ۶۳٫۳۳٪ | scoring + store + UI |
| ۲ | همه درست → ۱۰۰٪ | scoring |
| ۳ | همه غلط → −۳۳٫۳۳٪ | scoring |
| ۴ | همه نزده → ۰٪ | scoring |
| ۵ | تایمر صفر → قفل کامل، تغییر پاسخ رد می‌شود | timer + store + UI |
| ۶ | بستن و بازکردن وسط آزمون → ادامه با زمان واقعی | store + UI |
| ۷ | بازکردن بعد از پایان زمان → قفل فوری | store + UI |
| ۸ | پایان دستی پیش از موعد → تصحیح‌کننده | store + UI |
| ۹ | دقت اعشاری و جدایی مقدار خام از نمایش | scoring |

## معماری

```
src/core/      منطق خالص، بدون وابستگی به UI
  format.js    ارقام/درصد/ساعت فارسی، roundTo بدون خطای اعشار
  scoring.js   گزینه‌ها، وضعیت سوال، فرمول‌های درصد، یافتن کلید ناقص
  timer.js     مهلت مطلق، باقی‌مانده، انقضا، نسبت زمان
  model.js     مدل آزمون، وضعیت‌ها، اعتبارسنجی ورودی
  storage.js   آداپتور localStorage + بازسازی ایمن دادهٔ خراب
  store.js     مخزن و اکشن‌ها؛ هر تغییر بلافاصله persist می‌شود
src/ui/        لایهٔ نمایش
  dom.js / components.js / router.js / pwa.js
  views/       home، create، prepare، answersheet، corrector، result، history
  styles/app.css
sw.js          سرویس‌ورکر (کش آفلاین، fallback ناوبری)
manifest.webmanifest   متادیتای نصب (RTL/fa، آیکن‌ها)
tools/         سرور استاتیک سبک + بررسی یکپارچگی
tests/         تست‌های node:test + تست سرتاسری jsdom
```

اصل کلیدی: پاسخ‌برگ فقط محل ثبت پاسخ‌های کاربر است؛ تصحیح‌کننده کلید صحیح را جداگانه دریافت می‌کند و پاسخ کاربر با کلید مقایسه می‌شود.
